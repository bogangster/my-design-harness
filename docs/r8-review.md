## 5. 프로세스 회고

**오케스트레이션**
- state 갱신, 스냅샷, boundary, 재검증을 오케스트레이터가 단계마다 손으로 실행했다. 실수는 없었지만 강제 장치가 글(CLAUDE.md)뿐이다.
- 에이전트 정의(`.claude/agents/`)가 실행 세션에 등록되지 않아 general-purpose에 지침을 복사해 돌렸다 → `tools:` 제한이 적용되지 않았다. **이제 등록됨.** 단, planner·screen-builder는 도구가 Read/Write/Edit/Glob/Grep뿐이라 다음 실행부터 judge를 스스로 못 돌린다 → 재시도가 오케스트레이터 단계로 드러난다 (계측에는 좋고, 시간은 늘어남).
- 병렬 screen-builder가 하나뿐인 브라우저 패널을 서로 가져갔고, `data:` URL로 열려 tokens.css가 안 붙었다. 시각 확인은 오케스트레이터가 로컬 서버(`.claude/launch.json`)로 하는 게 맞다.
- 사용자가 진행 상황을 5번 물었고 "계속해"를 5번 보냈다 → 상태를 바로 볼 수단이 없다.

**외부 도구**
- uibowl 무료: 하루 검색 10회, 검색당 결과 3개. 자유 검색어("내 콘텐츠 관리")는 0건 — uibowl 고유 패턴·컴포넌트 이름으로만 검색된다. 컨셉 모드 1회로 하루 한도를 다 써서, S1 복귀가 필요한 실패는 당일 처리 불가.
- 피그마 Pro Full 시트: 하루 200회 중 19회 사용 — 여유 있음.

**인터뷰 (R0~R8)**
- R2·R3를 기본값("dd"/"ㅇㅇ")으로 빠르게 넘겼고, 완료 기준(R2 Q3)을 사용자가 직접 쓰지 않았다. 작업 흐름(R1-B)은 처음에 가정본으로 R2를 만든 뒤 실제 흐름으로 다시 썼다.
- R3 첫 초안이 "3~5단계" 규칙을 어겼다(8단계) → 5단계 + 모드 건너뛰기로 수정.
- judge 코드 리뷰에서 우회 4건(★N2 미마킹, 짧은 hex·별칭 액센트, 그룹 선택자 그림자, 스타일시트 무음 스킵)을 찾아 고치고 회귀 fixture로 고정했다.
